# 忍者パークシフト (Ninja Park Shift)

忍者テーマパーク（忍具屋・修行アトラクション・忍者茶屋）向けの、シフト作成が楽しくなるゲーミフィケーション型シフト管理アプリ。

従業員ごとの忍者アバターが、シフトの組まれ方（希望通りか／連勤日数／不慣れな施設への応援かどうか）に応じて
`happy` → `neutral` → `tired` → `unhappy` と表情を変える。マネージャーは各従業員の顔を見るだけで
無理なシフトになっていないかを直感的に把握できる。施設別・日別の売上と人件費も連動して可視化する。

詳しい企画背景は [CLAUDE.md](./CLAUDE.md) を参照。

## 主な機能

- **シフト表**: 日付ごとに忍者をドラッグ&ドロップで配置。施設別の必要人数・時間帯充足状況も表示(マネージャー専用)。
- **スタッフ管理**: 従業員の追加・編集・退職、アバターのカスタマイズ、ログインアカウントの発行(マネージャー専用)。
- **収支**: 期間合計の売上・人件費・損益、日別の損益グラフ、赤字連続日数のアラート表示。人件費は給与設定とシフト実働時間から自動計算(マネージャー専用)。
- **給与・ポスト設定**: ポジション別時給・研修中時給・社員月給、曜日×施設の必要人数を設定(マネージャー専用)。
- **用語管理**: 従業員名・施設名などの多言語「表記」を管理(マネージャー専用、翻訳ではなく表記の切り替え)。
- **マイシフト/自分の設定**: 従業員は自分のシフトを閲覧し、希望勤務日数・希望休み曜日・アバターを編集できる(編集はここのみ)。

## ロールベース権限(RBAC)

Supabase Authでログインし、ロールに応じて画面が切り替わる。

- **マネージャー(忍者頭領)**: 全機能にアクセス可能。
- **従業員**: 自分のシフト閲覧のみ(編集不可)、自分の希望・アバターの編集のみ可能。

ログイン情報(デモ用アカウント)は開発者が別途管理する。

## 技術構成（完全無料・オープンソースのみ）

- [React](https://react.dev/) + TypeScript + [Vite](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [DiceBear](https://www.dicebear.com/)（忍者アバターのベース生成、MITライセンス）
- [Lucide](https://lucide.dev/)（アイコン、MITライセンス）
- [Supabase](https://supabase.com/)（Postgres + Auth + Edge Functions、無料枠。本アプリ専用プロジェクトで、他アプリの認証基盤とは分離）

## 開発

```bash
cp .env.example .env.local   # 実際のSupabase URL/anon keyを設定
npm install
npm run dev
```

`.env.local` には `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` が必要(値は開発者に確認)。
初期データは `ninja_park_shift_dummy_data_updated.json` を元にSupabaseへ投入済み。以後の編集内容は
すべてSupabase(共有DB)に保存される(ブラウザのlocalStorageは表示言語の選択のみに使用)。

```bash
npm run build   # 型チェック + 本番ビルド
npm run lint    # oxlint
```
